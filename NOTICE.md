Modifications to aria2 in this build
------------------------------------
Stock limit checks were relaxed in src/OptionHandlerFactory.cc:
  max-connection-per-server   ceiling 16 -> 256
  min-split-size              floor 1M -> 256K, default 20M -> 1M
  piece-length                floor 1M -> 256K, default 1M -> 256K
  disk-cache                  default 16M -> 64M
  max-concurrent-downloads    default 5 -> 10
  connect-timeout             default 60s -> 15s
  max-tries                   default 5 -> 10

Corresponding source for the modified engine and this application is retained
in the project tree and available on request, per GPL-2.0 section 3.
